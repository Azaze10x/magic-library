Autonomous pipeline

One click. A new chapter.

World-Builder preps → Co-Writer drafts → Editor scores → if it passes, the chapter is saved.

01

World-Builder preps

Reviews the last chapter, builds writer guidelines, summarizes the story so far.

02

Co-Writer drafts

Drafts a new chapter from the plan, using tools to search the world and previous chapters.

03

Editor reviews

Scores 0–10 across 5 dimensions. Must hit 7+ to pass.

Scheduled runs

Cron-based scheduler — write every hour, every day, or every week.

Loop until it passes

If the Editor rejects it, the Co-Writer rewrites from the notes, up to 3 times.

Time-bounded

Hard 35-minute ceiling — no run ever pins your machine overnight.
